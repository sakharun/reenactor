# Событие

## Summary
Совмещённое бытие («быть» + «я»): количество качеств, связанных переходами и введённых в состояние цикла. События безобразны (в сетке), образы одеваются позже; в событие втягивает внутренний магнит, а не выбор личности.

## Current Understanding
- Событие = **количество качеств, связанных переходами и введённых в состояние цикла** (семинар 56)
- В событийной сетке события **безобразны** — структуры, замкнутые на себя и гоняющие по циклу качества притянувшихся; образы «надеваются» отображением на физический мир
- Этимология (семинар 53): событие = «событие»-совмещённое бытие: «быть» (вечность, суть) + «я» (личность со сверхфрагментарной скоротечностью) — см. [[Событийность]]
- Событие **втягивает по внутреннему магниту** (предрасположенность / отсутствие оттенка качества для предназначения); случайных событий нет
- В кольце события человек находится, пока не приобретёт нужные качества; повторы прохождения = карма/судьба (см. [[Событийное-кольцо]])
- Потенциал есть только у **первичных легальных** событий; у имплантированных извне — нет (см. [[Событие-имплант]])
- Личность реагирует на образные проекции событий, а не на события напрямую
- У каждого есть ось своей событийности; «твоё/не твоё» событие определяется совпадением вибрационного кода

## Contradictions / Uncertainty
- «Событие = цикл качеств» (56) vs «событие = совмещённое бытие, быть+я» (53) — взаимодополняющие уровни (ядро vs этимология)
- Точное число качеств в событии не приводится
