# Преподаватель

## Summary
«Перед подаватель» — работает с информационными посылами перед действием. Формирует мироощущение и жёсткие закладки (ограничение). Нижний уровень в четвёрке преподаватель / учитель / воспитатель / наставник.

## Current Understanding
- Этимология: по + пре + даватель = «перед подаватель» — даёт информацию перед действием
- Практику не даёт — работает только с информационными посылами
- Формирует **мироощущение** (физические свойства окружающего мира)
- Создаёт жёсткие закладки — «опорное мироощущение», планку, за которую сознание не откатывается
- Работает через ограничения: задаёт рамки, запреты («пасут» детей)
- Запускает внутреннее стремление к свободному движению (через ограничения)
- Отображения: религия (ограничения без обоснования), ЕГЭ, массовые учебные заведения
- Сейчас преподаватели доминируют даже там, где должны быть учителя/воспитатели
- Мужское начало (работает с образами)
- В жреческо-волховской системе: преподаватели = сам народ, верхушка = жреческие опорники
- Зоны проявления: ясли/детсад, школа, училище, институт — спектрально во всех четырёх

### Семинар 93: преподаватель, педагог и воспитатель
- **Педагог — качество воспитателя:** «Педагог — это небольшая часть воспитателя, это одно из качеств» (L404); преподаватель как роль четвёрки ещё уже — он работает только с информационными посылами перед действием (занятие 27).
- **Предметник наращивает «мясо»:** в схеме воспитателя «педагоги-предметники будут наращивать нужное мясо в виде научных знаний», тогда как воспитатель создаёт «скелет» из осмысления учениками себя как реализаторов внутренних интересов (L635).
- **Иерархия функций:** воспитатель — «отдельная специализация, в которую не всякий педагог попадёт. Педагог как специальность может привлекаться воспитателем как помощник» (L621).
- **Ограничение преподавателя:** он даёт логику и рамки, но не различает внутренний интерес ребёнка и не соединяет его с интересом общества — это качества воспитателя (L561–577); см. [[Качества-воспитателя]].
- **Без воспитателя:** если в структуре нет воспитателя, его функцию берёт [[Отображение-воспитателя|отображение]] или система через события (L424–432).
