# Родитель

## Summary
Родить тело. Мать — отвечает за материализацию, рождение тела с генетическими качествами двух родов.

## Current Understanding
- Родитель = родить тело
- Мать (Иньээ, Ийээ) — отвечает за материализацию, перенос в физический план
- Тело несёт генетические качества двух родов, стабильно зафиксированных в геноме
- Зона Ограничений — стабильность генетики
- Мать можно заменить словом родитель — в слове заложено сутьевое понимание
- Физическое тело = отображение подсознания, последняя стадия материализации
- Родитель ≠ Отец: родивший тело не всегда является отцом (направляющим по траектории)
- **Участие родителей в появлении ребёнка — 7–10% в лучшем случае (семинар 33):** при рождении выделяется потенциал на ребёнка, частично используется родителями на воспитание (системно, «не бесплатно»); почитание родителей = изучение их жизни для входа в родовую траекторию (см. [[Почитание]])
- **Воспитатель в семье — отец, не мать (семинар 33):** мать = хранительница очага = отображение Бога; отец создаёт внешнюю оболочку соприкосновения с внешним миром, готовит к прохождению по траектории, зная её (см. [[Отец]])

### Семинар 97: родитель — родивший тело
- **Этимология:** «"родитель" — слово, там два корня — "род" и "тело": родивший тело» (L128).
- **Не значит отец:** родивший тело «не значит участвующий в воспитании ребёнка. Соответственно, он может быть не отцом» (L128).
- **Отчество:** «дача отчества ребёнку не имеет отношения к родству по отцу. Отчество может дать и приёмный отец» (L126); см. [[Отчество]].
- **Отчим:** при взятии отчества отчима ребёнок «начинает служить роду отца, а не родителя. При этом пользуясь базой рода родителя» (L258).
- **Родители прививают обычаи:** «отец и мать воспитанием не занимаются… в основном занимаются прививанием ребёнку обычаев» (L230–232).
